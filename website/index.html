Everything in one place

An engine that feels familiar on day one

If you have used Roblox Studio, you already know your way around: the Explorer, Properties, parts, models and scripts all work the way you expect.

A Studio-style editor

Move, rotate and scale with snapping, insert parts and ready-made pieces, edit every property, undo anything.

Lua scripting

workspace, Instance.new, Touched, TweenService, task.wait: the API you know, with clear errors that point at the line.

Client and server

Scripts and LocalScripts, RemoteEvents and RemoteFunctions, live replication. Switch between the client's and the server's view while you play.

Real physics

Jolt Physics under the hood: falling, bouncing, welded models, moving platforms that carry players, raycasts.

GUI, sound and models

ScreenGuis with buttons and images, positional sound, and 3D models imported from OBJ, glTF and GLB.

Build a real game

File > Build Game makes a folder with your game's own .exe and icon. Zip it, share it: nothing else to install.

Git built in

Every project can be a repository: commit, browse history, branch, and push to GitHub from the Source Control panel.

Always up to date

RIFT checks for new versions and updates itself in a few seconds. Your projects and settings stay as they are.

Safe by design

Scripts run sandboxed: no file system, no network, a time limit on runaway loops. Installs without administrator rights.

Scripting

If you know Roblox Lua, you know RIFT

Scripts live in plain .lua files next to your scene, so you can edit them in RIFT's editor or in VS Code. Errors show the script and the line, and one click takes you there.

  • Scripts on the server, LocalScripts on the client
  • RemoteEvents, RemoteFunctions and BindableEvents
  • TweenService, CollectionService, DataStoreService
  • CFrame, Vector3, Color3, UDim2, Enum and friends

-- Spins, and gives a coin to whoever touches it.
local coin = script.Parent
local Players = game:GetService("Players")

game:GetService("RunService").Heartbeat:Connect(function(dt)
    coin.CFrame = coin.CFrame * CFrame.Angles(0, dt * 2, 0)
end)

coin.Touched:Connect(function(hit)
    local player = Players:GetPlayerFromCharacter(hit.Parent)
    if not player then return end
    local coins = player.leaderstats.Coins
    coins.Value = coins.Value + 1
    coin:Destroy()
end)

FAQ

Is RIFT free?

Yes. RIFT is free to download and use, and so are the games you make with it.

Is RIFT made by Roblox?

No. RIFT is an independent engine whose editor and scripting API are modelled on Roblox Studio, so the skills carry over. It is not affiliated with or endorsed by Roblox Corporation, and it does not connect to Roblox.

Can my games be played without RIFT?

Yes. Build Game makes a folder with your game's own .exe. Players just unzip it and play; nothing has to be installed.

Does it run on Mac or Linux?

Not yet: RIFT is made for Windows 10 and 11 (64-bit) with an OpenGL 3.3 graphics card, which almost every PC from the last decade has.

Is it multiplayer?

Games are single-player for now, but they already run as a client and a server with RemoteEvents and replication, exactly like Roblox, so your code is ready for it.

How do updates work?

RIFT checks GitHub for a new release when it starts. One click downloads it, updates RIFT in place and restarts it. You can turn the check off in Preferences.

How do I uninstall it?

Windows Settings > Apps > Installed apps > RIFT Engine > Uninstall. Your projects are never deleted.

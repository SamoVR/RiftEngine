# RIFT

A game engine and editor for Windows, scripted in Luau like Roblox Studio.

- **[Download RIFT](https://github.com/SamoVR/RiftEngine/releases/latest)**
- [Website](https://samovr.github.io/RiftEngine/)
- [Editor guide](docs/GUIDE.md), [scripting reference](docs/SCRIPTING.md), [changelog](CHANGELOG.md)
- [Report a problem](https://github.com/SamoVR/RiftEngine/issues)

This repository holds the releases, the website and the documentation. RIFT's source code is private.
